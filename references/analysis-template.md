# 论文精读模板

按论文内容取舍小标题，保留以下主线。不要用模板填充论文没有报告的信息。

## 1. 书目信息与链接

- 题名：
- 作者：
- 年份、venue / 发表状态与版本：
- 论文主页 / PDF / 代码：
- 核验说明：

## 2. 问题形式化

- 研究对象与任务：
- 输入、输出、目标或研究问题：
- 现有方法的具体缺口：
- 本文假设 / 要验证的主张：

## 3. 方法

### 总体流程

### 关键步骤

对每个步骤说明输入、机制、输出及作用。

### 关键公式

原式、符号含义、优化目标，以及它如何对应方法机制。

## 4. 实验设置与结果

- 数据集与任务：
- 模型、训练和评测设置：
- 基线与指标：
- 主结果：
- 消融与补充分析：
- 哪些研究问题得到回答，哪些仍未回答：

## 5. 批判性分析

- 关键假设是否成立，证据是什么：
- 比较是否公平，指标是否足以代表目标：
- 结果的适用范围与外部效度：
- 可能的混杂因素、失败模式与局限：
- 因果主张是否超出实验所能支持的范围：
- 作者明确承认的限制 vs. 阅读者推断：

## 6. 与已读论文的联系

仅填写能够从对话或阅读记录确认的论文；比较问题、监督信号、机制和证据。

## 7. 核心认识

用一小段写明贡献、最可信证据和最重要保留意见。

## 8. 阅读自检（8–12 道选择题）

先只呈现题目和选项。答案与解析暂不输出，等用户提交后再批改。
